# 肠上皮 marker 组合与相邻标签判别

这些 marker 用来提出和比较候选标签，不能代替旧项目的 COSG、raw counts mean、群内外 pct_expressed 和细胞级共表达检查。低检测率基因的“未检出”也不能直接视为生物学阴性。

| 候选标签 | 支持程序 | 最关键的替代解释与检查 |
| --- | --- | --- |
| LGR5+ Stem cells | LGR5、OLFM4、ASCL2、SMOC2；SOX9 辅助 | 与普通 progenitor 比较完整 stem 组合；单个 LGR5/OLFM4 不够。 |
| S-phase / G2/M TA cells | TA/progenitor 背景及 MKI67、TOP2A、PCNA 等增殖程序 | 用 cell-cycle score 与 phase 比例区分 0/1；增殖状态本身不证明另一谱系。 |
| Regenerative epithelial progenitors | OLFM4/ASCL2/SOX9 与部分 FABP1/KRT20/VIL1、REG4/TFF3/AGR2、AREG/ANXA1 等混合程序 | 与 REG4+ secretory progenitor、enterocyte progenitor、doublet/multiplet 比较；要求细胞级信号一致。 |
| Enterocyte progenitors / immature absorptive enterocytes | FABP1、KRT20、VIL1 等逐渐出现；progenitor 程序逐渐减弱 | 区分早期 enterocyte progenitor 和有 FABP1 但 ALPI/SI/APOA1/APOA4 近乎没有的 immature 群。 |
| Mature absorptive enterocytes | FABP1、KRT20、VIL1，辅以 HNF4A、CYP3A5、ALPI、SI、APOA1/APOA4、MTTP 等功能程序 | 与 immature、metabolic progenitor 比较多个成熟功能 marker 的比例，不以单个 CYP3A5 定义成熟。 |
| Metabolic absorptive progenitors | OLFM4/ASCL2/SOX9 残留 + 吸收程序；PPARG/PGK1/CA12/ANXA10 等代谢相关特征 | “Metabolic”是描述性状态；保留 progenitor 身份，比较 mature enterocyte 与混合技术信号。 |
| REG4+ secretory progenitors | REG4、TFF3、AGR2，同时保留 OLFM4/ASCL2/SOX9 | 与 cluster 2 的广泛混合程序及成熟 goblet 的黏液程序区分。 |
| Goblet cells | MUC2、SPINK4、CLCA1、FCGBP、TFF3、RETNLB | 多基因黏液程序优于 REG4 单基因；还需核对样本集中性。 |
| ER-stress epithelial cells | DDIT3、ATF3、HSPA5、XBP1 | 视为状态；与 stress-associated enterocytes、低质量/解离应激比较。 |
| Stress-associated enterocytes | 吸收上皮身份 + ATF3/DDIT3 等 stress 程序 | 保留 enterocyte 底层身份；与纯 ER-stress 群比较。 |
| Inflammatory epithelial cells | CXCL1、CXCL8、TNFAIP2、IFI6、ATF3、ANXA1、AREG 组合 | 与 regenerative 群的 AREG/ANXA1 和一般 stress 区分，检查 sample 分布与炎症程序一致性。 |
